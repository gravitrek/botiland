## 📋 Comment Utiliser les Données

### 1. Charger les Données Initiales

```bash
cd formations-casa/backend
source venv/bin/activate
python manage.py create_initial_data
```

**Résultat:**
- ✅ 15 catégories + 6 sous-catégories créées
- ✅ 9 types de formations créés
- ✅ 120 badges créés
- ✅ 8 accomplissements créés
- ✅ 30 fonctionnalités créées (toutes à 0 crédits)

### 2. Lancer le Backend

```bash
python manage.py runserver
```

Accès:
- API: http://localhost:8000/api/
- Admin: http://localhost:8000/admin/
- Docs: http://localhost:8000/api/docs/

### 3. Lancer le Frontend

```bash
cd ../frontend
npm install
cp .env.local.example .env.local
npm run dev
```

Accès: http://localhost:3000

### 4. Créer un Compte Admin

```bash
python manage.py createsuperuser
```

### 5. Approuver les Utilisateurs

1. Allez sur http://localhost:8000/admin/
2. Accounts > Users
3. Sélectionnez l'utilisateur
4. Cochez "Is approved"
5. Sauvegardez
